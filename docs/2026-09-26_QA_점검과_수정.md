## 결정한 것

- **인증 방식** — 운영자 비밀번호 하나 + 서명 세션 쿠키. 계정 여러 개·권한 등급은 아직 없다.
  외부 장치는 로그인 응답의 token 을 `Authorization: Bearer` 로 쓴다.
- **119 승인 범위** — 단말(세션)별. '상황 종료' 는 누른 단말의 승인만 푼다. 다른 단말의 승인은
  각자 종료하거나 `APPROVAL_TTL_MINUTES` 가 지나면 풀린다.
- **평시 OTP 거절** — 경보가 하나도 없으면 맞는 OTP 도 409. 화재가 아닌데 인명 위치가 열리는 것을 막는다.
- **비상문 fail-safe** — 전원이 꺼지면 잠금이 풀린다. 기존 화면의 전원 토글을 막지 않도록,
  '전원 OFF 로만 바꾸는 요청' 은 받아서 UNLOCKED 로 함께 바꾸고, '전원 OFF + LOCKED' 를 명시한 요청만 거절한다.
- **저장소** — DB 대신 `DATA_DIR/sensors.json` (임시 파일 + rename 으로 원자적 쓰기). 그래서 서버 1대로 운영한다.
- **CSP** — Next 문서의 nonce 없는 방식. 인라인 스크립트는 허용한다(정적 생성 유지). CCTV iframe 은 https 만.

## 테스트로 드러난 것

- 같은 밀리초에 두 번 수정하면 `updatedAt` 이 같아져 낙관적 잠금이 뚫렸다 — HTTP 로는 요청 사이 시간차 때문에 안 보였다.
  수정할 때마다 시각이 반드시 앞으로 가게 고쳤다.
- 숫자 id 로 저장된 센서는 `DELETE ?id=` 로 지울 수 없었다 — QA 도구의 자기 점검(잔여물 검사)이 찾았다. 입력 검증으로 막았다.
