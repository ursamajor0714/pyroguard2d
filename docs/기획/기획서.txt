  2. 🔍 초정밀 세부 기능 명세 및 예외 처리 규격 (Detailed Specifications)
--------------------------------------------------------------------------------

  [기능 01 세부 디테일] 2D 평면도 캔버스 & 센서 노드 상태 제어
    • 캔버스 Zoom & Pan 세부 제약 :
      - 최소/최대 확대 수치 : 0.5x ~ 5.0x (배율 이탈 시 바운스백 애니메이션)
      - 캔버스 더블 클릭(Double Click) 시 초기 1.0x 줌 및 중앙(0,0) 위치로 줌 리셋
      - 층 변경 시 줌/팬 위치 초기화 옵션 제공
    • 센서 노드 4가지 실시간 상태값 (Node Status Standards) :
      1) `NORMAL` (정상) : 센서 단색 흑백 아이콘 (녹색/무색 링)
      2) `MAINTENANCE` (점검/이동 중) : 황색 아이콘 + "점검 중" 툴팁
      3) `ALARM` (경보 발생) : 빨간색 깜빡임 (Red Pulse Animation) + 비상 삐- 경보음
      4) `OFFLINE` (통신 장애) : 회색 비활성화 아이콘 + "통신 무응답 3초 초과" 경고
    • 드래그 앤 드롭 예외 처리 :
      - 도면 캔버스 외곽 영역에 드롭(Drop) 시 배치 안 됨 ➔ 원래 보관함(Staging Dock)으로 자동 수거
      - [점검 모드] 토글 Off 상태에서는 마우스 드래그 불가 (노드 픽스 잠금 Lock 처리)

  [기능 02 세부 디테일] CCTV FOV 부채꼴 조작 & 라이브 모달 3대 액션
    • FOV 부채꼴 인터랙티브 스냅(Snap) 기능 :
      - 거리 핸들 : 최소 3m ~ 최대 30m 범위 드래그 조절 (1m 단위 Snap)
      - 화각 핸들 : 30° ~ 180° 광각/망원 조절 (15° 단위 Snap)
      - 회전 핸들 : 0° ~ 360° 방향 드래그 조절 (45° 방위각 Snap 및 1° 미세 조정)
      - FOV 부채꼴 마우스 호버 시 툴팁 : [카메라 ID / 거리 m / 화각 deg / 회전 deg] 실시간 표출
    • 경보 발생 시 CCTV 라이브 모달 팝업 내 3대 액션 버튼 :
      1) [오경보 처리 및 센서 점검 요청] 버튼 ➔ 경보 즉시 해제 및 해당 센서 "점검 중" 태그
      2) [119 긴급 화재 신고 발송] 버튼 ➔ 119 소방관 모바일 OTP 발급 및 긴급 화재 모드 격상
      3) [CCTV 화각 재조정] 버튼 ➔ 2D 화면 FOV 핸들 드래그 편집 모드 전환

  [기능 03 세부 디테일] AI 스냅샷 선명도 스코어 규격 & 119 OTP 10분 타이머
    • AI 스냅샷 캡처 품질 판단 세부 스코어링 기준 :
      - 1순위 (정상 정면) : MediaPipe Pose 17개 관절 100% 노출 + Face Yaw Angle < 15° (정면) + OpenCV Laplacian Blur Score > 100.0 (흔들림 없음)
      - 2순위 (Fallback) : 정면 얼굴 불발 시, 인체 박스 픽셀 크기가 가장 크고 Blur Score가 가장 높은 프레임 1장 무조건 캡처
      - 스냅샷 용량 최적화 : 1280x720 프레임 캡처 후 WebP 포맷(640x360 썸네일) 변환 저장 (파일 용량 50KB 이하 유지)
    • 119 소방관 모바일 OTP 온라인 승인 타이머 :
      - 119 소방대원 OTP 6자리 입력 성공 시 10분 카운트다운 타이머 (`09:59` ~ `00:00`) 작동
      - 10분 경과 시 개인정보보호법에 의거 2D 도면 잔류 인원/스냅샷 자동 암호화 재잠금 (Re-Lock)

  [기능 04 세부 디테일] 3대 방재 보완 센서 4단계 상태 모니터링
    • 전기 아크(Arc) 차단 센서 : EPS실 아크 감지 시 해당 층 일반 분전반만 국소 차단 + 2D 도면 경보 사운드 (Buzzer Alarm) On/Off 토글
    • 비상구 도어 & 비상문 자동개폐기 4단계 상태 디테일 :
      1) `LOCKED` (평시 방범 잠금) : 보안 잠금 유지 중
      2) `UNLOCKED` (화재 경보 해제) : 전자기 락 해제 완료 (대피 가능)
      3) `OPENED` (대피자 문 옒) : 대피자가 비상문을 밀고 나가는 순간 감지
      4) `CLOSED` (도어클로저 닫힘) : 대피 후 문이 저절로 다시 닫혀 연기 차폐 및 제연 효과 100% 유지 시각화

  [기능 05 세부 디테일] RS-485 소방 수신기 패킷 타임아웃 & B2 전기차 연기 반응
    • RS-485 통신 패킷 타임아웃 : 3초간 수신기 핑(Ping) 응답 없을 경우 2D 관제 UI 상단에 "소방 수신기 통신 끊김" 경고 유림
    • B2 전기차 충전구역 초동 연기 감지 : B2 천장 감지기 신호 감지 즉시 2D 화면이 `B2 주차장 도면`으로 자동 카메라 전환 + 충전구역 불꽃 빨간 점멸 + CCTV 라이브 자동 팝업

  4. ⚖️ 소방법(소방시설법) 및 기간별 의무 검사 타당성 검토
--------------------------------------------------------------------------------

  [법령 01] 소방시설 법정 자체점검 의무 (소방시설 설치 및 관리에 관한 법률 제22조)
    • 작동점검 (연 1회 이상) : 소방시설을 인위적으로 작동시켜 정상 작동 여부를 점검하는 검사.
    • 종합점검 (연 1회 이상) : 소방설비의 작동뿐만 아니라 법적 성능(수압, 감지기, 비상문) 종합 측정.
    👉 [PyroGuard 2D 보완 타당성] :
       법정 점검은 연 1회만 실시되므로 점검 사이 365일간 배관 수압 누출이나 소화전 이탈을 알 수 없는
       안전 공백 발생. 본 시스템은 365일 24시간 상시 감시(Continuous Monitoring)로 공백 철저 차단.
    🔗 [상호 연관 연결] ➔ [기능 01] 소화전 수압/문 감시 ↔ `app/api/sensors/route.ts`

  [법령 02] 소화기 내용연수 및 관리 기준 (소방시설법 시행령 제17조)
    • 분말소화기 법적 내구연한 : 10년 (10년 경과 시 의무 교체 또는 성능확인검사 필수).
