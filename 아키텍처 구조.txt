  🏢 PyroGuard 2D (파이로가드 2D) — 프로젝트 디렉터리 & 아키텍처 구조 명세
================================================================================

[전체 폴더 분류 요약]
  • 🎨 [프론트엔드 (Frontend)] : UI 화면, 2D 캔버스, FOV 조작, 모달, 상태 관리(Zustand)
  • 🛠️ [백엔드 (Backend)]     : Next.js API Routes, 미들웨어(middleware.ts), DB(AWS DynamoDB) 연동
  • 🔄 [공통 (Shared)]         : 타입 정의(TypeScript), 유틸리티 헬퍼 함수
