📌 [사용자 등록 완료 4대 1글자 단축키]
  • d          ➔ 개발 서버 구동 (npm run dev)
  • a          ➔ 변경 파일 전체 추가 (git add .)
  • b "메시지" ➔ 커밋 메시지 작성 (git commit -m "메시지")
  • c          ➔ 깃허브 원격 업로드 (git push)


--------------------------------------------------------------------------------
  💻 [실제 터미널 사용 예시]
--------------------------------------------------------------------------------
  1. 개발 서버 실행 시 : d
  2. 깃 파일 추가 시   : a
  3. 깃 커밋 작성 시   : b "기능 구현 완료"
  4. 깃 푸시 업로드 시 : c


--------------------------------------------------------------------------------
  📌 [컴퓨터 재부팅 시 영구 보관 세팅 코드]
--------------------------------------------------------------------------------
  1. 터미널(PowerShell)에서 메모장 열기:
     notepad $PROFILE

  2. 메모장에 아래 4줄 복사해서 저장(Ctrl + S) 후 닫기:
     function d { npm run dev }
     function a { git add . }
     function b ($msg) { git commit -m "$msg" }
     function c { git push }
