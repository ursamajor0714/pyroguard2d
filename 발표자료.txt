[도입부: 인사 & 기획 의도]
"안녕하세요! 팀 KH의 팀장이자 발표를 맡은 유근호입니다.

제가 이번에 개발한 프로젝트는 2D CAD 도면 기반의 실시간 통합 소방 방재 관제 시스템, PyroGuard 2D입니다.

발표는 [1] 팀 소개 및 개발환경 ➔ [2] ERD 엔티티 관계도 ➔ [3] 핵심 기능 설명 ➔ [4] 실시간 시연 및 Q&A 순서로 진행하겠습니다.

팀장이자 팀원은 저 혼자이며, 기획부터 프론트엔드, 백엔드, DB, 디자인까지 전 과정을 직접 개발 완료했습니다.

제가 이 시스템을 기획한 계기는, 고가의 방재 관제 시스템을 도입하기 힘들었던 10층 내외의 중소형 빌딩이나 영세 사업장에서도 부담 없이 도입할 수 있는 웹 기반 소방 관제를 구축하기 위해서입니다. 방재 사각지대를 해소하고 보다 안전한 사회를 만드는 데 기여하고자 제작하게 되었습니다."


[01. 개발환경 & 기술 스택]
"다음으로 개발 환경입니다. 프론트엔드는 React 19, 백엔드는 Next.js 15 (App Router)를 채택했습니다.

Next.js를 선택한 가장 큰 이유는 개발 생산성과 데이터 안정성 때문입니다. 별도의 백엔드 서버를 구축하지 않아도 자동으로 REST API 라우팅이 생성되어 빠른 개발이 가능했고, 프론트와 백엔드가 하나의 프로젝트에 있어 TypeScript 타입을 100% 공유함으로써 런타임 타입 에러를 사전에 방지할 수 있었습니다.

사용 언어로는 TypeScript와 Tailwind CSS를 사용했습니다. 자바스크립트의 타입 에러 위험을 극복하여 정적 안정성을 확보했고, Tailwind CSS를 통해 external CSS 파일 분리 없이 빠르게 관제 UI를 구축했습니다.

도구로는 Git, GitHub, Cursor AI와 함께, 실시간 CCTV 시연을 위한 Tailscale 가상 망(VPN) 및 DroidCam 연동 환경을 구축했습니다.

라이브러리 핵심 4가지는 다음과 같습니다.
1. D3.js: 1200x800 2D CAD SVG 도면의 5배 줌/팬 및 마우스 정밀 좌표 역변환 연산 담당
2. Zustand: 센서, 층, 전기차, 점검 이력의 상태를 전역에서 불필요한 리렌더링을 막고 관리하기 위해 핵심 라이브러리로 채택하게 되었습니다.
3. HLS.js: IP 카메라의 RTSP 비디오 피드를 웹 브라우저 표준 HLS 스트리밍으로 실시간 변환
4. Lucide React: 소화기, CCTV, 비상구 등 소방 관제 전용 직관적 베젤 아이콘 제공"


[02. 엔티티 관계도 (ERD) & DB 아키텍처]
"다음은 저희 시스템의 엔티티 관계도(ERD)입니다.

가장 핵심이 되는 중심 엔티티는 FloorMeta입니다. FloorMeta는 건물 21개 관제 구역(17F~1F, ROOF, B1~B3, 외부)의 2D SVG 도면 경로, 상주 인원수, 그리고 층별 센서들의 위험도(ALARM > OFFLINE > MAINTENANCE > NORMAL)를 종합 계산한 대표 상태를 실시간으로 저장하고 관리하는 루트 엔티티입니다.

구조적 특징을 말씀드리면,
첫째, FloorMeta를 중심으로 모든 데이터가 1:N 매핑 구조로 연결되어 있습니다. 층마다 여러 개의 센서(SensorNode), 상주 인원 위치(OccupantPos), 소방 점검 이력(FireLogEntry), 그리고 지하층의 전기차 충전기(EvCharger)가 1:N 구조로 관리됩니다.

둘째, CCTV 카메라의 부채꼴 시야 화각 연산 객체인 FovConfig만 센서 테이블에 1:1 임베드(Embed) 형태로 포함되어 2D 삼각함수 연산을 수행합니다.

셋째, EmergencySession은 별도의 독립 세션으로 분리 관리됩니다. 평시에는 개인정보보호법 제15조를 준수하여 286명 상주 인원 위치를 100% 마스킹 처리하다가, 화재 시 119 전용 6자리 OTP(119119) 승인이 떨어지는 즉시 비상 세션이 활성화되며 도면 위 👤 인명 위치를 동적으로 표출하도록 설계했습니다."


[03. 주요 기능 설명 (Key Features)]
"다음으로 주요 기능 소개입니다.

첫째, 2D CAD 도면 기반 센서 장비 관리 기능입니다. 2D CAD 도면 위에 소화기, 화재 감지기, 비상구 등 각종 센서 장비를 자유롭게 배치 및 삭제하고 실시간으로 감시 관리할 수 있습니다. SVG 벡터 방식을 사용하여 최대 5배까지 확대해도 해상도 저하나 깨짐 없이 세밀한 표시가 가능합니다.

둘째, 리얼타임 CCTV 관제 기능입니다. 배치된 CCTV를 바탕으로 실시간 카메라 입력을 초저지연 라이브 피드로 받아 관제판 및 비디오월에서 감시할 수 있습니다. 추후 YOLO AI 물체 감지 모델을 탑재하여 출입 인원 객체 추적 및 자동 감시 기능을 확장 적용할 예정입니다.

셋째, 전기차 충전기 및 주차 구역 관리 시스템입니다. 지하주차장 전체 구역의 차량 감시 및 충전기 15대의 상태(정상, 점검, 장애)와 내부 온도를 실시간 모니터링할 수 있습니다. 충전기 추가/삭제 및 상태 관리가 가능하며, 열폭주 징후 감지 시 관제 화면이 무조작으로 B2층 도면으로 자동 스위칭됩니다.

넷째, 비상상황 인원 감시 및 119 소방관 승인 기능입니다. 평시에는 개인정보 보호를 위해 인명 위치를 마스킹하다가, 119 소방대원 및 소방청의 보안 OTP를 입력받아 승인 시 도면 위에 👤 인명 구조 위치가 즉시 표시되어 신속한 인명 구조 활동을 지원합니다. 현재 시연은 인메모리 세션 방식으로 진행되지만, 향후 30초마다 보안 번호가 갱신되는 소방청 연동 TOTP 인증 파이프라인으로 즉시 확장할 수 있도록 구조를 설계했습니다.

이처럼 층별 세부 관제 현황 파악은 물론, 21개 층 전체 건물의 층별 상태집계 및 3D 입체 조감도 파악이 동시에 가능합니다."
