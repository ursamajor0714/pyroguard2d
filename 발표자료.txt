================================================================================
          PyroGuard2D 실시간 방재 관제 시스템 - 완성형 발표 대본 (구어체)
================================================================================

[ 1. 오프닝 및 시스템 소개 (Intro) ]

"안녕하십니까, PyroGuard2D 방재 관제 시스템 발표를 맡은 유근호입니다.

저희 시스템은 건물 내 화재 및 비상 상황을 24시간 실시간으로 감시하고 즉각 대처할 수 있도록 구축된 통합 방재 관제 플랫폼입니다. 

관제실 특성상 24시간 상시 모니터링이 필수적이기 때문에, 관제 요원의 시각적 피로도를 최소화하고 경보 발생 시 눈에 잘 띄도록 전역 다크 테마(#060913)로 디자인했습니다."


[ 2. 아키텍처 및 Next.js 채택 이유 (Architecture) ]

"저희가 프레임워크로 Next.js를 선택한 가장 큰 이유는 '프론트엔드와 백엔드의 완벽한 통합' 때문입니다.

별도의 백엔드 서버(Express 등)를 따로 띄우고 라우터 코드를 일일이 짤 필요 없이, 폴더 구조만으로 REST API가 자동 생성되는 '파일 시스템 라우팅'을 활용해 개발 효율성을 대폭 높였습니다. 

또한 프론트와 백엔드가 하나의 프로젝트에 있다 보니, 데이터 타입을 100% 공유하여 타입 에러를 사전에 방지할 수 있었고, 포트 분리로 인한 CORS 보안 에러도 원천 차단했습니다. 

통신 라이브러리 역시 외부 패키지(Axios) 없이 Next.js 자체 강화 fetch API를 사용하여 3초 주기 센서 폴링 시 네트워크 부하를 줄이고 자동 캐싱을 최적화했습니다."


[ 3. 핵심 기술 차별점 및 도면 인터랙션 (Core Differentiators) ]

"일반적인 단순 게시판이나 쇼핑몰 프로젝트와 달리, 저희 시스템은 복잡한 방재 현장을 직관적인 인터랙티브 UI로 풀어냈습니다.

첫째로, 1200x800 SVG CAD 도면 캔버스 위에서 D3.js 줌/팬 기능을 연동했습니다. 도면을 5배까지 확대하거나 이동시킨 상태에서도 마우스 좌표가 튀지 않고 정밀하게 배치되도록 좌표 역변환 연산을 구현하여, 센서를 마우스로 끌어다 원하는 위치에 자유롭게 배치하고 수거할 수 있습니다.

둘째로, 건물 21개 층 164개 센서의 상태를 실시간으로 전수 조사하여, '화재 경보 > 통신 단선 > 점검 중 > 정상'이라는 위험도 우선순위 알고리즘에 따라 각 층의 대표 상태를 자동으로 집계합니다. 이 데이터는 화면의 3D CSS 입체 조감도에 즉시 반영되어 전체 건물의 위험 현황을 한눈에 파악할 수 있습니다."


[ 4. 실무 관제 및 실시간 시연 환경 (Special Monitoring & Live Demo) ]

"최근 사회적으로 큰 이슈가 되는 지하주차장 전기차(EV) 화재에도 철저히 대비했습니다. B2층 EV 충전기 내부에 내장된 센서를 통해 충전 상태와 열폭주 징후를 실시간 감지하며, 열폭주 감지 시 화면이 수동 조작 없이 자동으로 B2층 도면으로 전환되어 즉각적인 초동 대처가 가능합니다.

또한 화재 경보 시 비상문이 자동으로 개방되며 관제판에서 원격으로 개폐 상태를 제어할 수 있고, 소방안전관리자의 법정 정기점검 이력(스프링클러, 감지기 등)을 일자별로 작성, 수정, 삭제할 수 있는 소방점검 이력 CRUD 시스템도 함께 통합했습니다.

CCTV 관제 파이프라인 역시 완비했습니다. IP 카메라의 RTSP 영상 프로토콜을 브라우저에서 직접 재생할 수 없는 한계를 극복하기 위해 HLS 웹 표준으로 이중화 변환하여 연결했습니다. 1초 간격 타임스탬프와 열화상 시뮬레이션 필터, 2x2/4x4 다채널 비디오월을 모두 지원합니다.

특히 실제 카메라 장비 연결 제약을 극복하기 위해, Tailscale 가상 망(VPN)으로 PC와 제 휴대폰 IP를 하나로 묶고 DroidCam 앱을 연동하여, 지금 화면에 보시는 것처럼 제 휴대폰 카메라의 실시간 피드가 관제판에 즉시 표출되도록 실제 시연 환경을 완성했습니다."


[ 5. 보안 파이프라인 및 미래 확장성 (Security & Closing) ]

"마지막으로 가장 중요한 생명 구조 보안 파이프라인입니다. 평시에는 개인정보보호법을 준수하여 건물 내 상주 인원 286명의 위치를 100% 마스킹 처리해 은폐합니다. 

그러다 화재가 발생하면 119 소방관이 전용 모달에서 6자리 비상 OTP(119119)를 입력해 인증받고, 그 순간 도면 위에 인명 위치 👤 이모지가 동적으로 마운트되어 신속한 구조 활동을 지원합니다.

현재 시연 버전은 서버 인메모리 세션 방식을 적용하였으나, 향후 실운영 전환 시 30초마다 보안 번호가 새로 갱신되는 소방청 연동 TOTP 인증 파이프라인으로 즉시 확장할 수 있게 연동 구조를 설계했습니다.

도면 자산 또한 현재의 2D SVG뿐만 아니라 향후 2.5D나 3D 도면으로 교체하더라도 유연하게 작동하는 확장성을 갖추고 있습니다.

이상으로 실시간 방재 관제 시스템 PyroGuard2D 발표를 마치겠습니다. 경청해 주셔서 감사합니다."
